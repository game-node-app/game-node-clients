Add selectable app themes: GameNode (default) plus PlayStation, Xbox, Switch and Big Picture styles. Colors, fonts and corners come from theme tokens; console themes also get a console-style home (focused game art behind rows of tiles, arrow-key navigation) and, on web, the navigation moves to the top bar. Pick a theme from the web sidebar or the mobile Preferences. Admin keeps the default theme.
